# AIStackScout — Approved Affiliate Programs

Master list of tools where we have an **APPROVED** affiliate program. Only tools on this list may use `/go/<slug>` Pretty Links, `(aff)` markers, or affiliate disclosure language in articles.

## Approved (Active Programs)

_None currently. Add tools here once their affiliate program approves the application._

Entry format when adding:
- **Tool name** — `/go/slug` — approved YYYY-MM-DD — network (PartnerStack / Impact / direct / etc.)

## How To Use This List

1. **Before drafting any article**, check this list against every tool you plan to feature.
2. **For tools on this list:** use `/go/<slug>` Pretty Link + inline `(aff)` marker + the standard affiliate disclosure language.
3. **For tools NOT on this list:** link directly to the tool's homepage. No `/go/` wrapper. No `(aff)` marker. No "affiliate" language for that tool.
4. If an article reviews 4 tools and only 1 has an approved program, the article still ships — but only that 1 tool gets affiliate treatment. The other 3 are direct links.
5. **The single CTA at the end of an article must point to an approved tool.** If none of the reviewed tools are approved, use the CTA for an internal action (newsletter signup, related article) instead of a tool link.
6. **Never assume a slug exists.** Verify the entry on this list AND that the Pretty Link is live in WP admin before any article uses it.

## When a Program Gets Approved

1. Add the entry to the "Approved" section above with the approval date and network.
2. Create the Pretty Link in WP admin (`Pretty Links → Add New`).
3. Verify the slug resolves to the correct merchant URL before any article links to it.
4. The disclosure block at the top of the post (handled by Code Snippets) only applies when the article actually contains affiliate links. If no approved tools are featured, suppress the FTC disclosure via the `_suppress_ftc_disclosure` post meta.

## Audit Trail

When a tool is removed from this list (program ended, account banned, payout dispute), do NOT just delete the entry — move it to an "Archived" section below with the removal date and reason. Then audit existing articles that link to that slug and convert them to direct homepage links.
