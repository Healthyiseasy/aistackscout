# Link Validation Rule — MANDATORY

Before publishing ANY article:
1. Extract all outbound URLs from the article content
2. Test each URL to verify it resolves (not 404, not timeout, not blank)
3. Verify each affiliate link uses a Pretty Link format (/go/toolname), never a raw URL
4. If any link is dead, times out, or is missing a Pretty Link redirect — DO NOT publish
5. Flag broken links and list them so I can fix before publishing
6. Every CTA must point to a working /go/ link, no exceptions
