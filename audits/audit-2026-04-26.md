# SECTION 4 — REPORTING SUMMARY

## Issues sorted by severity

### CRITICAL
*(none)*

### HIGH
1. **11 articles missing meta descriptions** — IDs 732, 733, 734, 735, 841, 862, 873, 900, 914, 925, 963. Search engines will auto-extract a snippet, often poorly. Remediation: open each post in Rank Math, fill the description field (≤ 160 chars).
2. **4 articles missing in-body H1** — IDs 732, 733, 734, 735. Body content starts at H2. Remediation: add a single in-body H1 to each, matching the focus keyword.
3. **PrettyLinks global default `link_sponsored = 0`** — per FTC + Google guidance, affiliate links should carry both `nofollow` and `sponsored`. Remediation: in `Pretty Links → Options`, flip "No Follow" *and* "Sponsored" both ON, then verify rendered links carry `rel="nofollow sponsored"`.
4. **Inline `(aff)` marker not present next to anchor text** — the audit spec required per-link inline markers; the site relies on the top-of-post block disclosure only. Remediation: decide whether to (a) accept block disclosure as sufficient (FTC-acceptable) and update the audit spec, or (b) add inline `(aff)` markers via the editor or a programmatic content filter.

### MEDIUM
5. **89 Pretty Links with `-2` duplicates** — duplicates dilute click analytics and create slug-collision risk. Remediation: pick the canonical slug for each tool, redirect the duplicate via Pretty Links' own redirect or delete it after confirming no live article links to it.
6. **2 orphan articles** — IDs 608, 611 receive no incoming internal links. Add 1–2 contextual links from related hub articles (e.g. link 608 from 609 hub and 607 hub).
7. **3 under-linked articles** — IDs 609, 701, 963 have only one incoming link.
8. **2 in-body images missing alt** — IDs 702 and 732 each have 1 image without alt.
9. **Pretty Links use 307 (temporary) redirects** — `prli_options.link_redirect_type = 307`. For long-lived affiliate destinations a 301 typically passes more signal and is the convention. Remediation: switch to 301 unless there is a deliberate reason for 307.
10. **3 posts at meta-description ceiling (155–160 chars)** — IDs 697, 701, 702 are likely to truncate in SERPs. Consider trimming to ~150 chars.

### LOW
11. **Plugin count discrepancy** — spec said 9 plugins, actual is 13. Reconcile the spec, or audit which plugins are unnecessary and can be removed (each plugin is attack surface).
12. **`/blog/` page included in post-sitemap** rather than page-sitemap — cosmetic, no SEO penalty.
